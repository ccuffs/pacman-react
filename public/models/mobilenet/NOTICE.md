# MobileNet v1 (0.25, 224) — pesos para TensorFlow.js

Os arquivos desta pasta (`model.json` e `group*-shard1of1`) são uma cópia, sem modificações,
do modelo pré-treinado publicado pelo projeto TensorFlow.js:

- Origem: https://storage.googleapis.com/tfjs-models/tfjs/mobilenet_v1_0.25_224/model.json
- Repositório relacionado: https://github.com/tensorflow/tfjs-models
- Arquitetura: MobileNet v1, multiplicador de largura 0.25, entrada 224x224

- Licença: Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0
  (texto completo no arquivo `LICENSE` na raiz deste repositório)

Os pesos foram treinados no conjunto de dados ImageNet, que possui termos de uso próprios
(https://www.image-net.org/download). Aqui os pesos são usados apenas como extrator de
características (transfer learning) em um projeto educacional.
